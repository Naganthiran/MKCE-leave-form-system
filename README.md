# MKCE Smart Leave Portal

## Project Overview
MKCE Smart Leave Portal is a web-based Leave and On-Duty (OD) Management System developed to automate the student leave approval process using a paperless workflow. The system provides role-based access for Students, Advisors, Mentors, and HODs with secure login functionality.

Students can apply for Leave/OD requests online, upload supporting documents, and track approval status in real time. The system follows a multi-level approval workflow to improve communication and reduce manual paperwork.

## Features
- Student Leave/OD Application
- Multi-Level Approval Workflow (Advisor → Mentor → HOD)
- Secure Login Authentication
- Real-Time Leave Status Tracking
- Evidence Upload Support
- Parent Notification System
- Digital Record Management
- Paperless Workflow

## Modules

### Student Module
- Login securely
- Apply Leave/OD
- Upload supporting documents
- Track request status

### Advisor Module
- View student requests
- Approve or reject requests

### Mentor Module
- Review leave requests
- Approve or reject requests

### HOD Module
- Final approval process
- Maintain records

## Workflow

Student Login
↓
Apply Leave/OD
↓
Advisor Approval
↓
Mentor Approval
↓
HOD Approval
↓
Parent Notification
↓
Status Update to Student
